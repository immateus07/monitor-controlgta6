# Monitor DualSense GTA VI
Busca a cada hora, minuto 17, por possíveis ofertas abaixo de R$ 600. Configure os Secrets TELEGRAM_BOT_TOKEN e TELEGRAM_CHAT_ID em Settings > Secrets and variables > Actions. Execute manualmente pela aba Actions > Monitor DualSense GTA VI > Run workflow para testar. O workflow precisa estar na branch padrão. Não publique credenciais. O monitor utiliza dados estruturados e buscadores; bloqueios, pré-vendas, vendedores não verificados e ofertas não indexadas limitam a cobertura. Preço não inclui necessariamente frete e parcelamento. O histórico evita repetir ofertas ao mesmo preço ou mais caras; apenas reduções geram novos alertas para o mesmo link e vendedor.

# Monitor Universal v5.0
Atualize monitor.py na raiz e substitua o conteúdo de .github/workflows/monitor.yml pelo novo monitor.yml. Preserve produtos.json, historico.json, requirements.txt e os Secrets. O arquivo produtos.json do ZIP é apenas exemplo para instalações novas. Execute manualmente com teste marcado. O bot consulta comandos a cada 15 minutos (podem ocorrer atrasos) e monitora cada produto uma vez por hora, exceto /buscar e teste manual. Use /ajuda pelo chat privado autorizado. Os comandos alteram produtos.json e o workflow salva configuração e histórico via git push. Não use webhook ou outro consumidor de getUpdates simultaneamente. Repositório público expõe preferências, links e histórico; nunca coloque dados pessoais ou credenciais nos arquivos. Não garante acesso a lojas bloqueadas, vendedor confiável, estoque ou preço final. Importação: /importacao ID | USD | cambio | frete BRL | impostos BRL define estimativa manual, sem cálculo fiscal automático. /link aceita links diretos de domínios permitidos. WAFUU, Best Buy e Amazon EUA são permitidos, mas não foram validados. Sem custos obrigatórios no runner padrão de repositório público. Evite edição simultânea durante execução; se git push falhar, confira o commit e repita a execução.
